## 第一阶段：基础核心

### 基础类型 (Basic Types)

- `string`、`number`、`boolean`：基础三件套
- `null` / `undefined`：空值，默认是所有类型的子类型（开启 `strictNullChecks` 后行为改变）
- `symbol`、`bigint`：用得少，了解即可

### 特殊类型 (Special Types)

#### `void`

表示函数没有返回值，实际返回 `undefined`。

```ts
function log(msg: string): void {
  console.log(msg);
}
```

#### `never`

表示永远不会出现的值，比如抛异常的函数或死循环。在类型系统中表示"空集" (Empty Set)。

```ts
function throwError(msg: string): never {
  throw new Error(msg);
}
```

#### `any`

跳过类型检查，**谨慎使用**。相当于告诉 TS "别管我"，用了就白写 TS 了。

```ts
let a: any = "hello";
a.toFixed();  // 不报错，但运行时报错
```

#### `unknown`

`any` 的安全替代品。表示"不知道什么类型"，使用前必须做类型收窄 (Type Narrowing)。推荐用于 API 返回值、用户输入等外部数据。

```ts
let u: unknown = "hello";
if (typeof u === "string") {
  u.toUpperCase();  // OK，已收窄为 string
}
```

### 数组 (Array)、元组 (Tuple)

#### 数组 (Array)

长度不限，所有元素同类型。写法 `string[]` 或 `Array<number>`，两种等价。

```ts
const ids: number[] = [101, 102, 103];
const names: Array<string> = ["Alice", "Bob"];
```

#### 元组 (Tuple)

固定长度，每个位置类型可以不同，顺序严格对应。常见场景：`useState` 返回值 `[state, setState]`、HTTP 状态码 `[200, "OK"]`。

```ts
const tuple: [number, string] = [200, "OK"];
const [count, setCount] = useState(0);  // [number, Dispatch<SetStateAction<number>>]
```

### 函数 (Functions)

给函数加类型的三个好处：入参校验、返回值可靠、编辑器补全。可选参数用 `?` 标记。

```ts
function add(x: number, y: number): number {
  return x + y;
}

function greet(name: string, title?: string): string {
  return title ? `${title} ${name}` : name;
}
```

### 对象 (Object)、接口 (Interface)、类型别名 (Type Alias)

#### 接口 (Interface)

描述对象结构，像一份契约 (Contract) 或蓝图 (Blueprint)。支持 `extends` 继承、同名自动合并。==描述数据结构时优先用 `interface`==。

```ts
interface User {
  readonly id: number;
  name: string;
  age?: number;  // 可选属性
}
```

#### 类型别名 (Type Alias)

比 `interface` 更通用，除了描述对象，还能定义联合类型、字面量类型等。不能重复声明。

```ts
type Point = { x: number; y: number };
type StringOrNumber = string | number;
```

#### `interface` 和 `type` 的区别

核心区别：`interface` 可重复声明自动合并，`type` 不行。

```ts
interface User { name: string; }
interface User { age: number; }   // ✅ 合并为 { name: string; age: number }

type User = { name: string; };
type User = { age: number; };     // ❌ 报错
```

## 第二阶段：进阶概念

### 联合类型 (Union Types)、交叉类型 (Intersection Types)

#### 联合类型 (Union Types)

值可以是多种类型之一，通过 `|` 连接，表示"或"的关系。TS 只允许访问各类型的共有成员，除非先用类型守卫 (Type Guard) 收窄。

```ts
let id: string | number;
id = "abc";
id = 123;
```

#### 交叉类型 (Intersection Types)

把多个类型合并成一个，通过 `&` 连接，表示"且"的关系。新类型必须同时满足所有成员。

```ts
type Admin = User & { permissions: string[] };
```

### 类型断言 (Type Assertion)、类型守卫 (Type Guard)

#### 类型断言 (Type Assertion)

告诉编译器"我知道这是什么类型"，只在编译时生效，不做运行时检查。不要滥用。

```ts
const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const canvas = <HTMLCanvasElement>document.getElementById("canvas");  // 等价写法
```

#### `typeof` 类型守卫

通过 `typeof` 收窄基础类型。

```ts
function print(value: string | number) {
  if (typeof value === "string") {
    console.log(value.toUpperCase());  // value 是 string
  } else {
    console.log(value.toFixed(2));     // value 是 number
  }
}
```

#### 真值检查 (Truthiness)

通过 `if (value)` 排除 `null`、`undefined`、`0`、`""` 等假值。

```ts
function printAll(strs: string | string[] | null) {
  if (strs) {
    // strs 收窄为 string | string[]
    for (const s of strs) {
      console.log(s);
    }
  }
}
```

#### `in` 类型守卫

判断属性是否存在，从而收窄联合类型。

```ts
type Cat = { meow(): void };
type Dog = { bark(): void };
function speak(animal: Cat | Dog) {
  if ("meow" in animal) {
    animal.meow();  // animal 是 Cat
  }
}
```

#### `instanceof` 类型守卫

判断是否为某个类的实例。

```ts
function getDate(date: Date | string) {
  if (date instanceof Date) {
    console.log(date.toISOString());  // date 是 Date
  } else {
    console.log(date);  // date 是 string
  }
}
```

#### 可辨识联合 (Discriminated Unions)

联合类型中的每个成员有一个共有的字面量字段（如 `kind`），通过判断该字段的值来收窄类型。

```ts
interface Circle { kind: "circle"; radius: number; }
interface Square { kind: "square"; size: number; }
function area(shape: Circle | Square) {
  if (shape.kind === "circle") {
    return Math.PI * shape.radius ** 2;  // shape 是 Circle
  }
  return shape.size ** 2;  // shape 是 Square
}
```

#### 类型谓词 (Type Predicates)

自定义函数返回 `x is Type`，在 `if` 分支内告诉 TS 类型判断结果。

```ts
function isString(value: unknown): value is string {
  return typeof value === "string";
}

const input: unknown = "hello";
if (isString(input)) {
  input.toUpperCase();  // input 是 string
}
```

### 字面量类型 (Literal Types)

把值限制为具体的字符串或数字，配合联合类型使用。

```ts
type Direction = "left" | "center" | "right";
type Status = 200 | 404 | 500;
```

### null 和 undefined

- `null`：表示"空值"，通常由开发者主动赋值
- `undefined`：表示"未定义"，通常由 JS 引擎自动产生（变量未初始化、属性不存在等）

默认 `null` 和 `undefined` 是所有类型的子类型，可以赋值给任何变量。开启 `strictNullChecks` 后，它们不再是其他类型的子类型，必须用联合类型显式处理。

```ts
// strictNullChecks 关闭：以下不报错
let name: string = null;

// strictNullChecks 开启：报错，必须显式声明
let name: string | null = null;
```

### 枚举 (Enum)

枚举 (Enum) 是一组命名的常量集合，让一组相关值更有语义。

```ts
enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

// 也支持数字枚举，默认从 0 自增
enum Status {
  Pending,   // 0
  Success,   // 1
  Failed,    // 2
}
```

> 枚举编译后会生成额外的 JS 代码，如果只是要一组字符串常量，用字面量联合类型 `"left" | "right"` 更轻量。

## 第三阶段：高级与泛型

### 泛型 (Generics)

泛型 (Generics) 是类型的"占位符"或"变量"。写代码时不指定具体类型，调用时才传入，既保留类型信息又不用写重复代码。

核心场景：同一个函数要支持多种类型。不用泛型的话，要么用 `any`（丢掉类型安全），要么每种类型写一份重载（重复代码）。泛型两个问题一起解决。

```ts
function identity<T>(arg: T): T {
  return arg;
}

const s = identity("hello");  // s 是 string，类型自动推导
const n = identity(42);       // n 是 number
```

#### 泛型约束 (Generic Constraints)

泛型不能是"任意类型"时，用 `extends` 约束它必须满足某个形状。

```ts
function logLength<T extends { length: number }>(arg: T): T {
  console.log(arg.length);
  return arg;
}

logLength("abc");     // ✅ string 有 length
logLength([1, 2, 3]); // ✅ 数组有 length
logLength(123);       // ❌ number 没有 length，编译报错
```

#### 泛型接口 (Generic Interface)

接口也可以接收泛型参数，常见于分页结果、API 响应等数据结构。

```ts
interface PaginatedResult<T> {
  items: T[];
  total: number;
}

const users: PaginatedResult<User> = { items: [{ name: "Alice" }], total: 1 };
```

### 高级类型 (Advanced Types)

#### `keyof`

取对象类型所有键名组成的联合类型。常见用法：配合泛型写通用的属性访问函数。

```ts
type UserKeys = keyof User;  // "id" | "name" | "age"

function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

#### `typeof`（类型上下文）

从已有 JS 变量/对象反向推导出 TS 类型，省去手写类型声明。

```ts
const config = { host: "localhost", port: 3306 };
type Config = typeof config;  // { host: string; port: number }
```

#### 映射类型 (Mapped Types)

遍历类型的所有属性并转换，语法 `[P in keyof T]: 新类型`。常见场景：给所有属性加 `readonly`、全部变为可选等。TS 内置的 `Partial`、`Readonly` 本质就是映射类型。

```ts
type MyReadonly<T> = {
  readonly [P in keyof T]: T[P];
};
```

#### 条件类型 (Conditional Types)

在类型层面做 `if/else` 判断。配合 `infer` 可以从类型中提取出内部类型。

```ts
type IsString<T> = T extends string ? "yes" : "no";
type A = IsString<string>;   // "yes"
type B = IsString<number>;   // "no"

// infer：从数组类型中提取元素类型
type Flatten<T> = T extends Array<infer U> ? U : T;
type C = Flatten<string[]>;  // string
```

### 工具类型 (Utility Types)

TS 内置的常用类型工具，本质是映射类型和条件类型的封装，不用手写就能做类型变换。

#### `Partial<T>`

所有属性变为可选。场景：更新接口时只传部分字段。

```ts
interface User { id: number; name: string; age: number; }
type PartialUser = Partial<User>;
// { id?: number; name?: string; age?: number }
```

#### `Required<T>`

所有属性变为必填。场景：严格模式下的表单数据校验。

```ts
interface Form { name?: string; email?: string; }
type StrictForm = Required<Form>;
// { name: string; email: string }
```

#### `Pick<T, K>`

从 T 中选取 K 指定的属性。场景：只需要某几个字段时。

```ts
interface User { id: number; name: string; age: number; }
type UserPreview = Pick<User, "id" | "name">;
// { id: number; name: string }
```

#### `Omit<T, K>`

从 T 中移除 K 指定的属性。场景：排除敏感字段如 `password`。

```ts
interface User { id: number; name: string; password: string; }
type SafeUser = Omit<User, "password">;
// { id: number; name: string }
```

#### `Record<K, V>`

构造键为 K、值为 V 的对象类型。场景：字典/映射表。

```ts
type UserMap = Record<string, { name: string }>;
// { [key: string]: { name: string } }
```

#### `Exclude<T, U>`

从联合类型 T 中排除可赋值给 U 的成员。

```ts
type All = "a" | "b" | "c";
type NoC = Exclude<All, "c">; // "a" | "b"
```

#### `Extract<T, U>`

从联合类型 T 中提取可赋值给 U 的成员。

```ts
type All = "a" | "b" | "c";
type OnlyA = Extract<All, "a">; // "a"
```

#### `NonNullable<T>`

从 T 中移除 `null` 和 `undefined`。场景：过滤掉可能为空的值。

```ts
type MaybeNull = string | number | null | undefined;
type Safe = NonNullable<MaybeNull>; // string | number
```

#### `ReturnType<T>`

获取函数返回值类型。场景：不修改源码就能拿到第三方函数的返回类型。

```ts
function getUser() { return { id: 1, name: "Alice" }; }
type UserFromFn = ReturnType<typeof getUser>; // { id: number; name: string }
```

#### `Parameters<T>`

获取函数参数类型，返回元组。场景：复用已有函数的参数类型，不用手写。

```ts
function createUser(name: string, age: number) {}
type Params = Parameters<typeof createUser>; // [string, number]
```
