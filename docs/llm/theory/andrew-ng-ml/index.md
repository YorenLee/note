# 吴恩达机器学习

## 监督学习（Supervised Learning）

监督学习使用**有标签的数据集（labeled dataset）**，其任务是学习一个**模型（model）**，使模型能够对任意给定的输入，对其相应的输出做出一个好的预测。

监督学习问题被分为**回归（Regression）**和**分类（Classification）**问题：

**回归问题（Regression）** —— 将输入变量映射到某个连续函数，即预测一个连续值。

**分类问题（Classification）** —— 将输入变量映射到离散的类别中，即预测一个离散值，预测的是一个有限的可能输出类别集合。

## 无监督学习（Unsupervised Learning）

给学习算法提供的示例不包含 **Y（输出）**，机器学习是找到一些结构或一些模式，或者只是在数据中发现一些有趣的东西。使用的数据集没有标签，不知道结果会是什么样子。

常见的无监督学习类型：

**聚类（Clustering）** —— 通过聚类的方式从数据中提取一个特殊的结构。

**异常检测（Anomaly detection）** —— 如金融系统中的欺诈检测。

**降维（Dimensionality reduction）** —— 可以将大数据集神奇地压缩为小得多的数据集，同时尽可能少地丢失信息。
