# 多元线性回归（Multiple Linear Regression）

## 多特征（Multiple Features）

单变量线性回归只有一个特征 x，例如只靠房屋面积预测房价。现实中房价还受卧室数量、楼层、房龄等因素影响，只用面积预测不够准。

**多特征** —— 每个训练样本由 n 个特征共同描述，例如一套房子用「面积、卧室数、房龄」三个特征表示。

**多元线性回归** —— 具有多个输入特征的线性回归模型，称为多元线性回归。

## 术语与符号

**$x_j$（第 j 个特征）** —— 下标表示第几个特征：$x_1$ 是面积，$x_2$ 是卧室数，$x_3$ 是房龄。

**$x^{(i)}$（第 i 个样本）** —— 上标仍表示第几个样本，与单变量时一样。

**$x_j^{(i)}$** —— 第 i 个样本的第 j 个特征，例如 $x_2^{(3)}$ 表示第 3 套房子的卧室数。

**n** —— 特征的数量，注意与样本数 m 区分。

**$w_j$（第 j 个特征的权重）** —— 衡量第 j 个特征对预测值的贡献大小。

## 模型形式

模型从一条直线变成 n 个特征的加权和，再加上偏置：

```math
f(x) = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b
```

以房价为例：$f(x) = w_1 \cdot \text{面积} + w_2 \cdot \text{卧室数} + w_3 \cdot \text{房龄} + b$。每个 $w_j$ 是对应特征「值多少钱」，$b$ 是基础价格，预测值就是各项贡献相加。

## 向量化（Vectorization）

把 $w$ 和 $x$ 看成 n 维向量，模型就是两个向量的点积：

```math
f(x) = \vec{w} \cdot \vec{x} + b
```

**代码更简洁** —— 向量化后一行代码完成全部计算，不用写 n 次乘法和加法。

**计算更快** —— 线性代数库（如 NumPy）在底层利用并行指令一次性算完所有分量，比 for 循环逐项累加快得多，特征越多差距越明显。

## 多元线性回归的梯度下降

成本函数仍是平方误差成本函数，只是参数从 w、b 变成 $w_1, \dots, w_n, b$ 共 n+1 个。梯度下降每一步同时更新所有参数：

```math
w_j = w_j - \alpha \frac{\partial J(w_1, \dots, w_n, b)}{\partial w_j} \qquad (j = 1, \dots, n)
```

```math
b = b - \alpha \frac{\partial J(w_1, \dots, w_n, b)}{\partial b}
```

代入平方误差成本函数求导后：

```math
w_j = w_j - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f(x^{(i)}) - y^{(i)} \right) x_j^{(i)}
```

```math
b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f(x^{(i)}) - y^{(i)} \right)
```

与单变量完全对应：误差项不变，只是更新 $w_j$ 时误差要乘上对应的特征 $x_j^{(i)}$。每个 $w_j$ 的更新公式都一样，只是使用自己那一列特征。

## 特征缩放（Feature Scaling）

**为什么要缩放** —— 当特征的数量级差异很大时（如面积 300~2000，卧室数 0~5），成本函数的等高线被拉成又长又细的椭圆。梯度下降沿最陡方向走，会像走之字形一样来回震荡，需要很多步才能到谷底，收敛很慢。

**缩放的目标** —— 把所有特征变换到相近的数值范围（大致 -1 到 1 附近即可，不需要精确），等高线恢复成接近圆形的碗，梯度下降可以直直地走向最小值。

常见做法：

**除以最大值（Max Scaling）** —— $x_j$ 除以该特征的最大值：$x_j / \max(x_j)$，结果落在 0 到 1 之间。

**均值归一化（Mean Normalization）** —— 先减均值再除以范围：$(x_j - \mu_j) / (\max - \min)$，结果大致落在 -1 到 1 之间。

**Z-score 标准化（Z-score Normalization）** —— 先减均值再除以标准差：$(x_j - \mu_j) / \sigma_j$，最常用，结果落在 -1 到 1 附近。

**预测时也要缩放** —— 模型是用缩放后的特征训练的，预测新数据时必须用同样的 $\mu$、$\sigma$ 缩放后再代入，不能直接喂原始值。

## 判断收敛

多元特征下同样要确认梯度下降是否收敛。常用方法是画学习曲线（learning curve）：记录每轮迭代后 J 的值，J 单调下降且趋于平稳，说明已收敛；J 上升，说明学习率 $\alpha$ 太大。

**自动收敛测试** —— 设置一个很小的阈值 ε（如 0.001），每轮迭代后 J 的下降量小于 ε 就认为收敛。ε 选多大需要试：太大可能提前误判，太小可能很久不触发。

学习率的选择原则见[梯度下降](./gradient-descent.md)。

## 特征工程与多项式回归

**特征工程（Feature Engineering）** —— 利用对问题的理解，从原始特征设计出新特征。例如只知道长和宽，可以构造出「面积 = 长 × 宽」，面积往往比单独看长、宽更能预测房价。

**多项式回归（Polynomial Regression）** —— 数据不是直线关系时，把 $x^2$、$x^3$ 等幂次当作新特征，仍用线性回归模型去拟合曲线。模型对参数仍是线性的，只是特征本身是非线性的。

**幂次特征必须缩放** —— $x^3$ 的数值范围比 $x$ 大得多，使用这类特征时特征缩放尤为重要。
