# 逻辑回归（Logistic Regression）

## 分类问题

前面几篇解决的都是回归问题：预测房价这类连续数值。现在转向分类问题（classification）：预测的是离散的类别，例如判断邮件是不是垃圾邮件、交易是不是欺诈、肿瘤是良性还是恶性。输出只有少数几种可能，而不是连续值。

**二分类（binary classification）** —— 只有两个类别的分类问题。通常把类别记为 0 和 1：1 是正类（positive class，如恶性肿瘤），0 是负类（negative class，如良性肿瘤）。

**为什么不能用线性回归** —— 拿一条直线拟合 0/1 数据、再以 0.5 为界判断类别，表面可行，但有两个问题：线性回归会预测出远小于 0 或远大于 1 的值，而类别只能是 0 或 1，这些输出没有含义；只要远处出现一个极端样本，整条直线就会被拉偏，导致原本分对的样本被分错。分类需要一个输出天然落在 0 到 1 之间的模型。

## 逻辑回归模型

逻辑回归把线性模型的输出「压」进 0 到 1 之间，工具是 sigmoid 函数。名字里带「回归」，但它其实是分类算法：「逻辑」一词来自它使用的 logistic 函数，即 sigmoid 函数。

**Sigmoid 函数** —— 定义：

```math
g(z) = \frac{1}{1 + e^{-z}}
```

曲线呈 S 形：z 很大时接近 1，z 很小时接近 0，z = 0 时恰好等于 0.5。

**模型形式** —— 先算线性组合 z = w·x + b，再送入 sigmoid：

```math
f(x) = g(w \cdot x + b) = \frac{1}{1 + e^{-(w \cdot x + b)}}
```

**输出的含义** —— f(x) 是「给定 x 时 y = 1 的概率」：$f(x) = P(y = 1 \mid x)$。例如 f(x) = 0.7，表示肿瘤有 70% 的概率是恶性；相应地 $P(y = 0 \mid x) = 1 - f(x)$。

## 决策边界

**怎么预测类别** —— 常用 0.5 作阈值：f(x) ≥ 0.5 预测 ŷ = 1，否则预测 ŷ = 0。

**阈值等价于看 z 的符号** —— sigmoid 在 z = 0 处等于 0.5，因此 f(x) ≥ 0.5 等价于 w·x + b ≥ 0：

```math
w \cdot x + b \ge 0 \;\Rightarrow\; \hat{y} = 1，\qquad w \cdot x + b < 0 \;\Rightarrow\; \hat{y} = 0
```

**决策边界（decision boundary）** —— 满足 $w \cdot x + b = 0$ 的直线（高维时是平面）把输入空间切成两块：一边预测 1，一边预测 0。模型学出的 w、b 决定边界的位置，训练逻辑回归本质上就是在学这条边界。

**非线性决策边界** —— 加上多项式特征（$x^2$、$x_1 x_2$ 等），边界可以是圆、椭圆或更复杂的曲线。例如 $w_1 x_1^2 + w_2 x_2^2 + b = 0$ 是一个圆。参见[多元线性回归](./multiple-linear-regression.md)中的特征工程。

## 逻辑回归的成本函数

**平方误差为什么不行** —— 若沿用平方误差成本函数，sigmoid 的 S 形会让 J(w, b) 变成非凸函数（non-convex），布满局部最小值；梯度下降可能停在某个局部最小值，到不了全局最小值。逻辑回归需要专用成本函数。

**损失函数** —— 单个样本的损失，也叫对数损失（log loss）或交叉熵损失（cross-entropy loss）：

```math
L(f, y) = -y \log(f) - (1 - y) \log(1 - f)
```

**分情况理解** —— 对 y = 1 的样本，损失是 $- \log(f)$：预测 f 越接近 1，损失越接近 0；f 越接近 0，损失趋向无穷大。对 y = 0 的样本，损失是 $- \log(1 - f)$：f 越接近 0，损失越接近 0；f 越接近 1，损失趋向无穷大。即：预测对了损失小，自信地预测错了损失爆炸。

**成本函数** —— 对所有样本求和再平均：

```math
J(w, b) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log f(x^{(i)}) + (1 - y^{(i)}) \log \left( 1 - f(x^{(i)}) \right) \right]
```

**凸函数** —— 这个 J 是凸函数，只有一个全局最小值，梯度下降不会卡在局部最小值。

## 逻辑回归的梯度下降

把新成本函数代入梯度下降，更新公式和线性回归几乎一模一样：

```math
w_j = w_j - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f(x^{(i)}) - y^{(i)} \right) x_j^{(i)}
```

```math
b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f(x^{(i)}) - y^{(i)} \right)
```

**与线性回归唯一的区别** —— f(x) 的定义不同：线性回归里 $f(x) = w \cdot x + b$，逻辑回归里 f(x) 是 sigmoid 函数。公式长得一样，是因为两个成本函数求导后恰好得到相同的形式。

**其余照旧** —— 向量化、特征缩放、判断收敛的做法都适用，见[梯度下降](./gradient-descent.md)。

**多分类** —— 类别多于两个时（如识别 10 种手写数字），需要 Softmax 回归等多分类方法，见[多分类 Softmax](../dl/softmax.md)。
