# 过拟合与欠拟合（Overfitting and Underfitting）

## 三种拟合状态

模型的复杂度和数据匹配的程度，有三种典型状态：

**欠拟合（underfitting）/ 高偏差（high bias）** —— 模型太简单，连训练数据本身的规律都没学到，训练集上误差就很大。例如数据是曲线，却只用一条直线去拟合。

**过拟合（overfitting）/ 高方差（high variance）** —— 模型太复杂，把训练数据「背」了下来，连同数据里的噪声一起学进去。训练集上误差很小，但对没见过的样本预测很差。

**恰好拟合（just right）** —— 模型复杂度和数据匹配，既抓住了规律，又不过分纠结于噪声。这是训练的目标。

**偏差与方差** —— 偏差（bias）指模型对真实规律的系统性偏离，欠拟合是高偏差；方差（variance）指模型对数据波动的敏感程度，过拟合是高方差。两组术语指的是同一回事。

**分类问题同样会过拟合** —— 决策边界扭曲到把每个训练点都圈进去，就是过拟合。

## 为什么会过拟合

特征太多、样本太少时，模型很容易「背下」每一个训练样本，把噪声当成规律。例如 100 个参数去拟合 10 个样本，总能找到一条曲线穿过所有点，但这条曲线对新数据毫无预测能力。

**识别过拟合的信号** —— 训练集误差很小，但在新的测试数据上误差很大。

## 解决过拟合的三个办法

**增加训练数据** —— 数据越多，模型越难「背下」所有样本，只能学到真正的规律。缺点：数据不一定总能拿到。

**减少特征（特征选择）** —— 只保留最相关的几个特征，降低模型复杂度。缺点：被丢掉的特征里可能含有用信息。

**正则化（regularization）** —— 保留所有特征，但限制参数的大小，从而压低模型复杂度。最常用，也是本篇的重点。

## 正则化

**核心思想** —— 过拟合的曲线往往依赖很大的参数值，才能扭出弯弯绕绕的形状；把参数变小，曲线就变平滑，趋近简单模型。做法：在成本函数后面加一项对参数的「罚款」。

**正则化成本函数** —— 在任意成本函数后加上惩罚项：

```math
J(w, b) = \frac{1}{m} \sum_{i=1}^{m} L\left( f(x^{(i)}), y^{(i)} \right) + \frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2
```

**惩罚项** —— $\frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2$ 是全部参数平方之和，再乘上正则化参数 λ。参数越大，惩罚越重，逼着模型用小参数。

**b 不惩罚** —— 惯例上不惩罚偏置 b：b 只负责上下平移，不改变曲线形状，罚不罚影响不大。

**正则化参数 λ** —— 权衡「拟合数据」与「保持参数小」：λ = 0 等于不正则化；λ 太大，所有 w 被压到接近 0，模型退化成一条水平线，反而变成欠拟合。λ 需要调参找到合适的值。

## 正则化线性回归

平方误差成本函数加惩罚项后，梯度下降的更新多出一个收缩项：

```math
w_j = w_j - \alpha \left[ \frac{1}{m} \sum_{i=1}^{m} \left( f(x^{(i)}) - y^{(i)} \right) x_j^{(i)} + \frac{\lambda}{m} w_j \right]
```

```math
b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f(x^{(i)}) - y^{(i)} \right)
```

**收缩的直觉** —— 把 w_j 的更新整理成：

```math
w_j = w_j \left( 1 - \alpha \frac{\lambda}{m} \right) - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f(x^{(i)}) - y^{(i)} \right) x_j^{(i)}
```

每一步先把 w_j 乘上一个略小于 1 的系数（收缩一点点），再做通常的梯度更新。这正是「正则化」名字的直观含义。

## 正则化逻辑回归

成本函数加上同样的惩罚项（L 是对数损失，见[逻辑回归](./logistic-regression.md)）：

```math
J(w, b) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log f(x^{(i)}) + (1 - y^{(i)}) \log \left( 1 - f(x^{(i)}) \right) \right] + \frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2
```

梯度下降的更新同样多出一个收缩项，和正则化线性回归完全对应，唯一的区别仍是 f(x) 是 sigmoid 函数。sigmoid 曲线越平滑，决策边界越简单，越不容易过拟合。
