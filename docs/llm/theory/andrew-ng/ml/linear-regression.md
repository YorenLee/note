# 线性回归模型（Linear Regression）

## 什么是线性回归

线性回归是监督学习中回归问题最简单的模型：根据输入特征预测一个数值。典型例子：给定房屋面积，预测房价。

模型的形式是一条直线：`f(x) = wx + b`

**w（weight，权重）** —— 决定直线的斜率。

**b（bias，偏置）** —— 决定直线的截距。

模型学习的目标，就是找到合适的 w 和 b，让预测值 **ŷ（读作 y-hat）** 尽可能接近真实值 y。

**单变量线性回归（Univariate Linear Regression）** —— 只有一个特征 x 的情形，即 `f(x) = wx + b`；特征多于一个时就是多元线性回归（Multiple Linear Regression）。

## 术语与符号

**训练集（training set）** —— 用来训练模型的数据集，每个样本由「输入特征 x 和输出目标 y」组成。

**x（feature，特征）** —— 输入变量，例如房屋面积。

**y（target，目标）** —— 输出变量，例如房价。

**（x<sup>(i)</sup>, y<sup>(i)</sup>）** —— 第 i 个训练样本，上标 (i) 只是编号，不是幂。

**m** —— 训练样本的总数。

## 如何衡量预测好坏

模型给出预测后，需要一个标准衡量「预测值和真实值差多远」，这就是成本函数（Cost Function），详见[成本函数](./cost-function.md)。

有了成本函数，再用梯度下降（Gradient Descent）找到让成本最小的参数，详见[梯度下降](./gradient-descent.md)。
